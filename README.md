# 💪 Protein Website

A modern, responsive website for browsing and buying protein supplements. It helps fitness enthusiasts compare products, check nutrition details, and order quickly on any device.

## Features

- Product catalog with whey, casein, plant-based, and mass gainer proteins
- Filters by type, flavor, and price
- Nutrition details for each product
- Search and sort by name, brand, or goal
- Shopping cart with live total
- Checkout flow
- Responsive design for mobile, tablet, and desktop

## Tech Stack

- HTML, CSS, JavaScript

## Getting Started

```bash
git clone https://github.com/amulyadas07/protein-website07.git
cd protein-website07
```

Open `index.html` in your browser to view the website.
